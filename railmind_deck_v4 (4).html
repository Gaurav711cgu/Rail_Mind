From Disruption to Network-Wide Impact

The railway network is modeled as a directed graph of stations and sections. When a disruption is detected, the agent runs a depth-limited BFS from the origin station, applying a calibrated delay-transfer function at every hop.

01
Calibrated Transfer Function Each hop carries forward 70% of inbound delay; congestion-heavy sections amplify it up to 1.3×.

Zero-Trust Operations Ledger

Cryptographic Operations & State Serialization

Every dispatch decision is tied to a verified controller identity (left) and written into an append-only ledger (right). Each block carries the agent that made the call, a human-readable summary, and a SHA-256 hash chained to the previous block — so any retroactive edit to a past decision breaks the chain and is instantly detectable on "Verify Ledger".
